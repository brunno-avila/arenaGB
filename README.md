# ArenaGB 

A ArenaGB é um projeto que desenvolvemos na disciplina de Desenvolvimento Web I, da Universidade do Contestado (UnC). A ideia foi criar um site de jogos em que os jogadores possam se cadastrar, escolher um jogo e apostar.

Um dos jogos do site é a **Roleta do JOB!**. Nela, o jogador escolhe quanto quer apostar, gira a roleta e tenta conseguir combinações que dão prêmios. Também é possível acompanhar o saldo de créditos.

## O que tem no projeto?

- Cadastro e seleção de jogadores;
- Página com os jogos;
- Roleta do JOB!, com apostas e prêmios;
- Exibição do saldo do jogador;
- Páginas de histórico e painel.

## Tecnologias utilizadas

Para desenvolver o site, usamos:

- **HTML5** para montar as páginas;
- **CSS3** para personalizar o visual;
- **JavaScript** para fazer os jogos e as interações funcionarem;
- **Bootstrap 5** para ajudar no layout e na responsividade.

## Como rodar o projeto

Você pode clonar o repositório com o comando:


git clone https://github.com/brunno-avila/arenaGB.git


Depois, é só abrir a pasta do projeto no VS Code e executar o arquivo 'index.html' no navegador, ou pode usar a extensão **Live Server**.
